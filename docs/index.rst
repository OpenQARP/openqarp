========
OpenQARP
========

.. rst-class:: qarp-lede

Quantum applications, built in layers.  Blocks describe circuits, primitives
describe what to extract, engines describe how they run, and a compiled C++
core runs them.

.. container:: qarp-actions

   .. code-block:: shell

      pip install openqarp

   `Get started <source/getting_started.html>`_
